# GitPilot 1.1.0

[Versión oficial publicada](https://github.com/JhosepAC/gitpilot/releases/tag/v1.1.0) el 2026-11-12 (America/Bogota). Manifiesto OpenPGP y tag SSH verificados sobre e2bc12a. Los nueve adjuntos públicos coinciden con el candidato probado.

Esta versión corrige la asignación de identidades y separa la autenticación SSH de la firma de commits. El perfil elegido se aplica mediante vista previa, confirmación, respaldo y verificación, incluso cuando existen valores globales o locales anteriores.

## Cambios principales

- Conservación de propietario, grupo y ACL de los archivos Git durante reemplazo y recuperación en Windows.
- Claves de autenticación y firma por perfil, elegidas desde el explorador del sistema. Firma SSH u OpenPGP opcional u obligatoria.
- Un perfil sin clave propia impide reutilizar claves SSH de otra identidad. La firma no proporciona implícitamente una clave de autenticación.
- Zoom por teclado en Windows y reflujo comprobado hasta 200%.
- Menú lateral vertical con iconos; directorios por nombre y consulta de las rutas asignadas a cada identidad.
- SQLite 3.54.1, corrección de GLib y actualización de dependencias de desarrollo. Backports con fuentes, licencias e integridad verificables; auditorías en CI.

## Descargas y actualización

| Plataforma | Archivo |
| --- | --- |
| Windows x64 | GitPilot_1.1.0_x64-setup.exe |
| Debian 12 amd64 | GitPilot_1.1.0_amd64.deb |

Cierra GitPilot y exporta tus ajustes desde Configuración antes de actualizar. Tras instalar, revisa las claves y reaplica los perfiles desde Directorios. Editar un perfil guarda sus datos; la escritura de configuración Git requiere revisar y confirmar la propuesta. La recuperación de escrituras está disponible desde Actividad.

Git 2.39.5 o posterior. Windows requiere WebView2 Runtime; Debian requiere WebKitGTK 4.1 y Secret Service para las funciones de credenciales y respaldo protegido. ## Validación y límites

CI de Windows y auditorías de dependencias sobre el commit de distribución. El flujo del candidato valida instalación limpia, actualización Windows desde 1.0.0, migración, reapertura, reinstalación y desinstalación con datos sintéticos. Windows verificó configuración efectiva, autor y recuperación con Git CLI; las pruebas reales de remoto SSH y firmas SSH/OpenPGP conservan su evidencia Linux previa. Los límites de revisión manual, incluida la selección efectiva de un archivo en el explorador, se detallan en el [plan de validación](https://github.com/JhosepAC/gitpilot/blob/main/docs/releases/PLAN_1_1_0.md). La revisión y las pruebas adicionales Linux se omitieron por decisión del responsable; la compilación Debian no acredita una validación completa de su instalación o interfaz.

El instalador Windows se distribuye sin Authenticode y puede aparecer como editor desconocido. Verifica la firma OpenPGP del manifiesto y las sumas antes de instalar. Las variables de entorno y opciones explícitas de Git externas pueden prevalecer sobre la configuración de perfiles. HTTPS mantiene su helper configurado. Por seguridad, la escritura Git en Windows rechaza archivos comprimidos, cifrados, sparse o con streams alternativos; no elimina sus metadatos.

## Verificar los paquetes

La huella de la clave pública de distribución es `47B1 0C26 AF8B C961 5DE3 9C58 13EF 6F27 474B 5E0F`. Coteja la huella completa antes de importarla.

```sh
gpg --show-keys --fingerprint GitPilot-release-key.asc
gpg --import GitPilot-release-key.asc
gpg --verify SHA256SUMS.txt.asc SHA256SUMS.txt
sha256sum --check SHA256SUMS.txt
```

BUILD-INFO.txt identifica el commit y la ejecución de compilación. Los avisos legales y THIRD_PARTY_NOTICES.txt se incluyen con los paquetes.
