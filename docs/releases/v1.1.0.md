# GitPilot 1.1.0

**Candidato en validación.** Las correcciones de dependencias se documentan en `docs/security/REVIEW_1_1_0.md`. La revisión y pruebas adicionales Linux se omiten por decisión del responsable.

GitPilot separa la identidad de autor, la autenticación SSH y la firma de commits por perfil. Al asignar un perfil, revisa y confirma la propuesta para que Git use sus valores aunque existan configuraciones anteriores. Los cambios conservan respaldo, verificación y recuperación desde Actividad.

- Claves de autenticación y firma seleccionadas desde el explorador del sistema; firma opcional u obligatoria.

- Sin clave SSH propia, el perfil impide reutilizar claves de otra identidad.

- Menú vertical con iconos, directorios por nombre y consulta de rutas asignadas a cada identidad.

- Correcciones de minimatch, SQLite y GLib; retirada de RSA y proc-macro-error vulnerables o sin mantenimiento. Backports con origen, licencias e integridad verificables.

## Actualizar

Cierra GitPilot y exporta tus ajustes desde Configuración antes de instalar. Tras actualizar, revisa las claves y reaplica los perfiles desde Directorios. Editar un perfil guarda sus datos; la escritura en Git requiere revisar y confirmar su aplicación.

Windows x64: `GitPilot_1.1.0_x64-setup.exe`. Debian 12 amd64: `GitPilot_1.1.0_amd64.deb`. Git 2.39.5 o posterior. Licencia CC BY-NC 4.0.

El instalador Windows carece de Authenticode. Antes de distribuir, adjunta LICENSE, NOTICE, BUILD-INFO.txt, SHA256SUMS.txt, su firma OpenPGP y la clave pública de distribución. Verifica la huella publicada por el mantenedor y las sumas según `docs/RELEASING.md`.

## Condiciones para publicar

- Desktop CI aprobado para el SHA final de main y candidato de ambas plataformas generado desde ese SHA.

- Instalación limpia y actualización Windows desde 1.0.0 verificadas con datos aislados, incluyendo reapertura y migración. La validación adicional Linux se omite por decisión del responsable.

- Firma de manifiesto y tag de distribución verificados antes de publicar.
